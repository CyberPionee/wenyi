# 自治翻译质量方案（设计）

[翻译流程](pipeline.md) · [配置](configuration.md)

目标：人只定红线与例外，发现—修复—评估—放行尽量由 AI 闭环完成。本文是设计口径，不代表当前实现已全部落地。

## 人机分工

| 人做 | AI 做 |
|---|---|
| 上传书、选目标语言与自治档位 | 预理解、术语、翻译、润色、审校 |
| 一次设定红线/阈值（政策） | 浅自校、互审、Autofix、评估打分 |
| 例外（反复失败、术语冲突裁定） | 不过线自动重做；全绿机器验收并导出 |

人不做：逐条审 Review、逐项勾验收单、整本回译确认、固定集 A/B 实验。

## 合并后总流程

```text
[准备]
  风格指南 + 全书概要/章摘要 + 术语初表
          │
[主体生产]
  译(style + 梗概 + 术语 + 滚动源译对)
    │
    ├─ 浅自校（C-batch，宽而浅）
    │
    └─ 高风险 / 低置信 / 抽样
           ↓
       互审（深）→ 影子修 → Autofix
          │
[统一]
  术语回写 + residual sweep
  （可选）译文决策锚 → 注入后续批
          │
[终校]
  风险定向回译 + 抽样 → 低分自动重做
          │
[评估与验收]  最小验收套件（L0–L3）
  L0 规则红线：auto_qa / sweep          ── 规则
  L1 忠实/风险：定向回译、对照            ── 模型
  L2 一致：术语漂移、人名/称呼            ── 规则
  L3 通顺/文风：LLM judge（固定 rubric）  ── 模型
          │
     全绿？──否──► 自治环（局部重译 / Autofix）──► 复验
          │是
          ▼
   机器「验收通过」→ 导出
   连续 N 次失败 → 升级给人（唯一常规人工点）
```

不设独立「试点章」阶段。风格与梗概沿用准备阶段产物；译后决策锚为可选增强。

## 自治环

评估与生产共用同一修复通道：

```text
┌─────────────────────────────────────────────┐
│  自治环（每章 / 全书）                        │
│                                             │
│  译/润 ──► 浅自校 ──► 修复候选               │
│               │                             │
│               ▼                             │
│        写入 Autofix 影子链                    │
│               │                             │
│               ▼                             │
│  L0–L3 评估 ──过线?──► 机器验收 → 导出       │
│               │ 否                           │
│               ▼                             │
│     自动重修 / 局部重译 ◄── 失败原因回填      │
└─────────────────────────────────────────────┘
```

原则：

1. 不过线不导出（`auto_qa_strict` 及评估阈值）。
2. 建议（C-batch、回译低分等）必须进 Autofix 候选，不能只停在笔记。
3. 失败可续跑；连续 N 次失败才升级为人。
4. 验收结论由机器规则签发，人不逐项勾选。

## 最小验收套件

服务**单书交付**与流水线门禁，不做固定集 A/B 研发对比。

### 分层与执行者

| 层 | 查什么 | 谁评 | 不过线时 |
|---|---|---|---|
| L0 完整/硬残留 | 空译、数字残留、未译片段、术语冲突、Review 未决 | 规则（auto_qa / sweep） | 阻断导出，自治环重做 |
| L1 忠实/风险 | 风险定向回译低分、实体/数字不对齐 | 模型对照 | 低分段进 Review/局部重译 |
| L2 一致 | 术语漂移、人名/称呼统一 | 规则 + 术语库 | 回写或局部重做 |
| L3 通顺/文风 | 翻译腔、语气、与 style/决策锚贴合 | LLM judge（固定 rubric，可双评） | 低分段加码修复 |

### 机器验收门（全绿才放行）

1. `auto_qa.passed`：空译 0、冲突 0、残留 0、Review 未决 0。
2. 术语漂移 / 人名不一致 = 0（或已锁定/已裁定）。
3. 风险回译低分率 ≤ 阈值（如 5%）。
4. L3 judge 分 ≥ 阈值。

全绿 → 自动标「验收通过」→ 允许导出。否则进自治环；连续失败升级给人。

### 阈值与报告

- 阈值/红线政策由人在档位里设定一次，运行中只读。
- 每次运行生成机器 QA 报告（计数、低分段列表、judge 摘要），可看可不看，不作为人工门禁。
- 不做固定集 A/B、人工评分表、逐项验收签字。

## 风险门控回译

整本回译不作为默认质量手段，只作 L1 探测器。

```text
全书翻译
        │
┌───────┼────────┐
▼       ▼        ▼
高风险段  抽样段   低风险段
(人名/   (5–15%)  (叙述套话)
对话/长句/术语)    │
│        │        └── 不回译
└───┬────┘
    ▼
定向回译 / 对照打分
    │
低分才进 Review / 局部重做
```

- 高风险：术语密集、对话、长难句、指代多、sweep 报警、低置信。
- 抽样：每章 5–15%，首尾章可加密，用于趋势与门禁。
- 整本回译仅用于特殊验收场景，不进默认产品路径。

## 浅自校与互审

| 道 | 对应 | 职责 | 范围 |
|---|---|---|---|
| 浅自校 | C-batch self_revision / chapter_selfcheck 等 | 明显错、漏、不通 | 宽而浅 |
| 互审 | Review 取证 + 影子修订 | 一致性、术语、语气、逻辑 | 窄而深：高风险/低置信/抽样 |

## 可选译文决策锚

轻量可选，不强制、不新增人工步骤。

- 来源：接近定稿的译文（通常早期批次）。
- 形式：极短「必用 / 禁用 / 样例」，可由 C-batch / editorial 自动凝成。
- 注入：与 `style` 并列进入后续批；默认关，或仅漂移风险时开。
- 不替代：`analysis.style`、全书概要、章节摘要、术语表。
- 适用：人名、称呼、文风跨章漂移；已稳则可不做。

## 实现优先级

| 优先级 | 项 | 改代码？ | 说明 |
|---|---|---|---|
| P0 | 自治·准配置：`auto_qa_strict`、`review_autofix`、术语 auto-lock | 否 | 配置与默认档 |
| P0 | 回译改为风险门控 + 抽样（关整本默认） | 设计已定，实现小改 | L1 |
| P0 | 最小验收套件口径：L0–L3 职责、机器门、阈值政策 | 否（设计） | 合入验收 |
| P1 | 可选译文决策锚 | 小改 | 抗漂移 |
| P1 | 浅自校→互审分流（只深审风险段） | 要 | 控成本 |
| P2 | 术语变更自动回写 | 要 | 统一 |
| P2 | C-batch / 回译低分自动进 Autofix | 要 | 闭环 |
| P2 | 失败自动重试与红线局部重做 | 要 | 修到过线 |
| P3 | 机器 QA 报告与趋势（Web/report） | 小 | 可观测；不含 A/B |

### 阶段 2：让 AI 修到过线

1. **候选入链**：自审、回译、润色候选走 fix → verify → publish。
2. **术语回写**：锁定/改名后扫描历史章节，定点替换或局部重译。
3. **失败自动重试**：空译、格式坏、冲突自修；连续 N 次失败再升级为人。
4. **红线重做**：L0 红灯章节局部重译 + 局部 Review，不整本推倒。

### 阶段 3：自评与加码

1. **风险定向回译 / 对照打分**：低分段加 Review 或重译（L1）。
2. **可选译文决策锚**：定稿译文凝「必用/禁用」表，按需注入。
3. **置信度门控**：低置信加证据或换强模型；高置信降消耗。
4. **L3 judge 阈值门**：通顺/文风分纳入机器验收，不靠人读全书。

## 自治档位（产品向）

| 档位 | 用途 | 人介入 | 评估 |
|---|---|---|---|
| 自治·速 | 快速出稿 | 只处理例外 | L0 必过；L1–L3 报告不阻断 |
| 自治·准（推荐） | 正式交付 | 红线例外 | L0–L3 全绿才导出 |
| 自治·精 | 出版级 | 例外 + 可选终读 | 准 + 更严阈值/更密抽样 |

「自治·准」= 严格 auto_qa + 全量 Autofix + 浅自校入链 + 术语 auto-lock + 风险终校 + L0–L3 机器门 + 失败自动重做。

## 与现有能力的边界

已具备、直接复用：`analysis.style`、全书概要与章节摘要、术语抽取与按章注入、滚动源译对、后文参考、Review 取证与影子修订、Autofix 发布、residual sweep、`auto_qa` 汇总。

已补强（截至 autonomous-quality-v3）：C-batch 与回译低分入 Autofix、术语回写（按源文命中定点替换）、评估不过线经 Autofix 自动重做（max_auto_redo_rounds）、L3 固定 rubric 与可选双评、机器验收报告与评估明细/趋势、自治档位与阈值可配、可选风险范围审校。

明确不做：整本回译默认路径、强制试点章、固定集 A/B、人工逐条审、人工逐项验收签字。

本文对应分支 `feat/quality-autonomy-v2` 上的质量自治讨论口径；落地以具体实现与测试为准。
